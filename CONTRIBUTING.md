# Contributing

Ploos Domains is an MIT-licensed project. Issues and pull requests are welcome.

- Keep organization boundaries and DNS permissions explicit.
- Add regression tests for authorization changes.
- Never include live DNS provider tokens or real customer data in tests.
- Prefer small, reviewed PRs and standard free GitHub Actions checks.
- Document user-visible behavior in English and Norwegian when relevant.
- Flag any external DNS writes as security-sensitive changes.
